# LG01 v005 製作報告

以 `FEEDBACK_v005.md` 為準，使用 Blender 5.2.2 背景 Python 建立兩根倒木及各自 LOD1。v003／v004 檔案未修改。檢查圖使用 Cycles 64 samples、AgX、灰霧世界光與弱太陽；`check_side.png` 相機高度 1.65 m。

## 三輪調整

| 輪次 | 修改與檢查 |
|---|---|
| 1 | 沿用 v004 的灰棕材質和 v003 的苔厚度，移除 v004 沿 X 固定週期的橫向 `sin` 幾何。以拉長的 3D 雜訊做縱溝與大尺度起伏。初算苔遮罩 A/B 為 60.8%／59.9%，過量。 |
| 2 | 增加苔塊缺口，遮罩降為 51.9%／51.4%；側拍卻只見頂部細綠邊，顯示苔帶方位仍不對。 |
| 3 | 調整苔帶往鏡頭側垂落，減少地衣密度；檢查時發現網格角度 0–2π 與負角度遮罩不一致，於同輪修正角度環繞並重算。最終可見半圓表面遮罩 A/B 為 51.4%／51.1%。 |

## 必答自我檢查

1. **這看起來像瓦楞紙或波浪板嗎？** 不像。最終側拍沒有等間距的橫向波紋；細小裂紋仍可見，但方向不規律。
2. **苔大約佔可見表面幾成？** 約 **5.1 成**。以鏡頭側及上表面半圓取樣，A 51.4%、B 51.1%；視角、遮擋和光線會使畫面中的綠色面積與此幾何遮罩數值不同。
3. **沒看說明的人會說這是一根長滿苔的倒樹嗎？** 會。側拍可辨識深色樹皮、沿長度延伸的不規則苔塊和撕裂端；仍比設定圖整齊。

四件均有 `Longitudinal_UV`，本地最低 Z = 0、縮放 (1,1,1)，掃描貼圖已打包。快速 QA：四件開放邊、多面共邊、零面積面均為 0。完整 LOD0 QA：面方向不一致、重複頂點、內翻島與 Z 衝突均為 0。

完整 QA 的 `pass=false` 原因是規格要求 A/B 為兩根獨立木頭，檢查器將 B 視為 detached；單根內沒有浮空島。長向 UV 採重複平鋪，QA 因而回報 UV 重疊；此 UV 不適合直接烘焙唯一貼圖。上述兩項均保留並已接受。
