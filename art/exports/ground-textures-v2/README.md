# GT01–GT08 地形材質候選總覽

![八種材質對照](GT01-GT08-contact-sheet.png)

| ID | 用途 | 視覺檢查 | 場景使用注意 |
|---|---|---|---|
| GT01 | 灰綠草地 | 小白花與枯草可見 | 花點在大面積鋪設時重複；搭配散布草模型。 |
| GT02 | 灰褐土路 | 細碎石、踩實土與淡車轍可見 | 道路邊界由地形遮罩而非本圖決定。 |
| GT03 | 深褐林地 | 落葉、苔與細根可見 | 與草層混合並用實體落葉打散重複。 |
| GT04 | 灰色溪邊礫石 | 局部濕痕可見 | 與岸線、水面及實體石塊銜接。 |
| GT05 | 河谷暖灰岩 | 礦物紋與裂紋可見 | 長裂紋平鋪重複明顯，宜混合其他岩石。 |
| GT06 | 茶田紅褐土 | 淺水平耕痕可見 | 田壟與茶樹由地形和獨立模型補足。 |
| GT07 | 水田濕泥 | 淺水窪可見 | 水窪重複明顯；較深水面由場景系統處理。 |
| GT08 | 不規則花崗石板 | 不齊石板、土苔縫可見 | 大石板輪廓重複明顯，適合小廣場及遮罩混合。 |

每種均有 2048 × 2048 的 Albedo、Normal、URP Mask Map 與 3 × 3 平鋪預覽。八組 `validation.json` 的三張圖左右和上下最大像素差均為 **0**；此數值只證明邊界像素一致，不證明場景品質或手機效能。全部 AI 原圖為 1254 × 1254，後製放大並週期化，放大不增加原生細節。各材質的製作原圖、腳本和個別限制見各 GT 目錄。

已目視檢查八張 3 × 3 預覽和這張總覽。**尚未在 Unity Terrain 實際匯入、調整每層尺度、檢查 URP 光照與混合，也未測手機效能。** 面積較大的區域應使用地形遮罩、不同圖層及少量實體細節打散週期圖案；GT08 尤其不宜直接無限重複。
