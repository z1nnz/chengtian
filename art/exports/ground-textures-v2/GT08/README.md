# GT08 不規則花崗石板地形材質

- 用途：B 區石板廣場及較硬的步行地面；場景形狀由地形塗層決定。
- 內容：2048 × 2048 Albedo、Normal、URP Mask Map，以及已目視檢查的 3 × 3 平鋪預覽。
- 視覺檢查：石板大小與方向不齊，縫內可見土與少量苔。四邊沒有明顯接縫；大石板輪廓在連續鋪設時重複明顯，宜限於小區域或配合遮罩、獨立石板與旋轉變體打散。
- 技術檢查：`validation.json` 記錄三張圖四邊最大像素差均為 0。AI 原圖為 1254 × 1254，輸出放大至 2048 × 2048；放大不增加原生細節。
- 製程：選用第二版 AI 原圖位於 `art/references/ground-textures-v2/GT08/`；`art/source/ground-textures-v2/build_gt08.py` 可重建輸出。
- 狀態：材質候選已完成；Unity 內實際比例、光照、地形混合及效能尚未驗證。
