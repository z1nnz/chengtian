## SK01 北向石峰

- 4096×1024 RGB 不透明貼圖；另輸出左右各 2048×1024 與 2048×512 手機版。
- 頂部漸層至天空色，供既有 `SM_Skyline_Arc` 弧面以天空色淡出混合。弧面模型在 `art/codex-1108-moon-and-skyline-arc` 分支，本分支未複製它。
- 從整張 4096 圖切成兩個 2048 半張；逐像素確認分割結果與原圖一致，沒有獨立生成造成的中縫。
- v001 峰形重複成等距三角形；v002 改成不對稱台峰、細峰和斷稜，但實際看圖後仍有明顯幾何化尖峰。依工作包每階段最多兩輪規則，停止修改並標為候選。
- 自評 40/100。不能當作已與方向圖一致的最終貼圖；需人工美術重畫峰形、補山腰微小建築影、與相鄰方向及晨昏色調對比。尚未測試 Unity 材質或手機效能。
