## 共同做法

- 先生成三視圖（4 張）、自評選一張，再做灰模、線框、LOD，最後上貼圖。
- 原點在樹幹底部中心，z = 0 是地面；根往下埋 0.3 m（z 最低 −0.3）。Blender −Y 是正面（FBX／Unity 是 −Z）。
- 一棵樹一個網格／LOD，兩個材質槽：`M_TR01_Bark`（樹皮）、`M_TR01_Leaves`（葉）；LOD3 只有葉材質。同一樹種三個變體共用一套貼圖（`TR01_Shared/Textures/`）。
- 葉片：BaseColor 的 alpha 做 alpha clip 0.5、雙面；BaseColor 匯入時開 Mip Maps Preserve Coverage（參考值 0.5）。
- 風：寫在頂點色 `Wind`（FBX 線性色）：R 擺動權重（主幹 0、大枝 0.02–0.3、細枝 0.3–0.5、葉團 0.6–1），G 每團相位，B 高度 0..1。
- 碰撞：`<ID>_Collision` 是包住主幹的 8 邊柱（z 0–3 m），渲染關掉、當 MeshCollider 用，或換成同尺寸 CapsuleCollider（數字在 model_info.json `collision_capsule`）。樹冠不擋人。
- LOD 切換距離（model_info.json `lod_switch_distance_m`）：LOD0→1 在 60 m、1→2 在 100 m、2→3 在 260 m、1500 m 以外淡出。Unity 檢查程式依這些距離與專案 LOD bias（2.0）換算 LODGroup 高度，0.98 封頂。
- minTier 都是 `low`（樹是場景主體，最低畫質也要有）。
- 重建：`blender -b --factory-startup -P art/source/trees-b/build_trees_b.py -- TR01 --force`；審圖：`blender -b art/source/trees-b/blend/TR01_v001.blend -P art/source/trees-b/preview_trees_b.py -- TR01 <hero|grey|wire|lods|ruler|ten|far>`；Unity：`Unity.exe -batchmode -projectPath apps/game -executeMethod YunJing.Editor.TreesModelCheck.Run -trees TR01 -quit`。

## TR01 松

真實比例的松，地面以上 13.0–13.6 m，不是盆景比例。下半段主幹光禿，留著脫落枝的斷樁；第一根大枝約 5 m 高。大枝一層一層從主幹接近水平伸出，外段微垂、末端上翹；上層枝也不短，所以老松的樹冠頂端偏平。

**做法（2026-11-13 重做，和 TR02 柏同一套）：** 使用者看過柏樹定版後指示「用同樣做法開始做松樹」。舊版的雲團葉團整個拿掉（舊腳本只留在本機備份，不提交）。
- **枝幹：** 照金色靈樹的長法，大枝 → 中枝 → 小枝 → 末梢一層層長出，用 Skin 融成一體。
  - 中枝在水平面上往左右攤開，所以每根大枝托著一片扁平的枝盤，這是松的特徵。
  - 大枝粗細壓在主幹的 0.38 倍以下，每根是獨立的 Skin 島。第一版太粗，在主幹細的上段被融進主幹，造成一圈縮頸，已修好。
  - 樹頂加兩根短枝，主幹尖端收在最上層枝盤裡面。第一版主幹頂上單獨浮著一撮針葉，已改掉。
- **葉：** 不用雲團。葉子是一束束松針，像刷子一樣，每束長 30–45 cm，各自一張葉卡（兩個三角面），角度各不相同。松針一簇簇長在小枝末端，朝上、朝外。LOD0 每棵約 5,100–6,200 束。
- **顏色：** 每束松針依位置取 8 個色階之一：在枝盤上方、外側、朝上的亮，在枝盤下方、內側的暗，另加少量隨機。所以每片枝盤都是上亮下暗。每束針葉本身也是向光的半邊亮、背光的半邊暗。
- **LOD1／LOD2：** 每張卡畫一整簇（4 種色階）。卡的大小是在 Unity 量過葉面覆蓋率後才定的。
- **樹幹去塑膠感（使用者回饋「樹幹還是很塑膠」）：**
  - 原因：主幹一圈只鋪 1 格樹皮，粗的根部被橫向拉長約 3 倍，細的樹皮板塊變成大片橫向軟波紋。
  - 修法：照胸高處的周長決定一圈鋪幾格（每格 0.8 m，一圈 3 格），樹皮恢復成直向板塊和深溝。這個設定只加在 TR01 的主幹上（`uv_k`／`uv_tile`），TR02 不受影響。
  - 主幹表面的板塊起伏加深，多一層細紋，外輪廓不再是光滑圓管。
  - 斷樁改成短而粗、微微下垂的斷枝。舊版貼在樹幹上像一塊方塊，第一次改又太細，像竹籤。

## TR02 柏

古林的主角，地面以上約 10.2–10.8 m。主幹粗而扭，有樹瘤、隆起的樹皮板塊和深溝。下枝長、上枝短，樹冠往上收成尖頂。深綠偏青，苔從根部往上爬（最高約 1.8 m）。

**做法（2026-11-12 重做）：** 使用者看過雲團版後指示「全部打掉重做，參考剛剛做的金黃樹，不要再雲團了」。現行版照金色靈樹（`art/source/golden-spirit-tree/v001`）的長法，壓進遊戲預算：
- **枝幹：** S 形主幹，一層層長出去：主枝 → 中枝 → 小枝 → 末梢。用 Skin 修改器融成一體，分叉從母枝長出，看得到木頭。
  - 主枝與中枝比母枝細很多，各自是獨立的 Skin 島，從母枝裡面長出；接點沒有鼓包。
  - 低處主枝整根平順抬高到 2.4 m 以上，不硬壓，所以沒有折角。
- **葉：** 不用雲團、不用葉團球。葉子一簇簇長在末梢上，每簇 4–9 片，各自有角度。柏的一「片」是一枝扁平鱗葉（35–55 cm），每片是一張兩個三角面的葉卡，LOD0 約 5,300–6,100 片。
- **顏色：** 每片葉子依位置選 8 個色階之一：高處、外側、朝上的比較亮，下方、內側、下垂的比較暗，另加少量隨機。每個色階是圖集裡的一格，URP Lit 不用改 shader。
- **LOD1／LOD2：** 每張卡畫一整簇（4 種色階），色階與近景同一套。卡的大小是在 Unity 量過葉面覆蓋率後定的，所以遠近顏色一致：四級平均葉色差 ≤ 5%。
- **樹幹去塑膠感：**
  - 樹皮貼圖：對比拉大 2.1 倍，裂紋壓到近黑；法線改用未模糊的圖，強度 16；光滑度 0.07 以下。
  - 主幹表面：做出寬圓板塊加窄深溝，隨高度扭轉。
  - 面數分配：主幹單獨減面，保留四成木頭面數，輪廓不再有折角。
  - 貼圖對應：主幹改用「高度＋繞主軸角度」，根部外擴不再拉成直條紋；改前量到 130 倍拉伸，改後根部已無此問題，全樹最大約 35 倍，在一小段斷枝殘樁上。

# B 批：TR03 樟、TR04 楓、TR05 銀杏、TR06 垂柳、TR07 梅

分支 `art/b-1111-tr-trees-broadleaf`，疊在 A 批（TR01、TR02）之上。共同做法、碰撞、LOD 切換距離、minTier、貼圖命名都和 A 批相同（見最上方「共同做法」）。

## B 批共同做法：闊葉樹引擎 `tr_broad.py`

A 批的長法照搬到闊葉樹時，樹冠會長歪、長空。B 批改用「空間殖民」：
- **枝幹：**
  - 先在樹冠範圍裡放一團團葉團，每團撒吸引點，大枝從主幹往吸引點一步步長過去，自然分叉。
  - 枝粗用管徑模型：母枝截面約等於子枝截面和。
  - 長好的枝幹切成一根根枝條，每根記住自己的母枝。用 A 批的 Skin 融合木頭（`tr_skin.py`）融成一體，再減面到預算。
- **葉：**
  - 葉卡只長在每根末梢最後約 1 m。
  - LOD0 的卡往葉團外表面拉一段，所以一團團看得出形狀；團與團之間看得到枝條和天空。
- **明暗：**
  - 每張卡依「在葉團裡的高低」「在樹冠裡的高低與外緣」「朝向」選 8 個色階之一：葉團上亮下暗。
  - 著色法線混合葉團法線與樹冠法線，URP Lit 不改 shader。
- **LOD1／LOD2：** 每張卡畫一整簇（圖集右上 4 格），色階與近景同一套。
- **調色以 Unity 截圖為準：** Unity 比 Blender 亮且暖。工作包對顏色的要求（紅要沉、金要舊）都是在 Unity 畫面確認的。

共用程式改動（都是選填參數，A 批不受影響）：
- `tr_skin.py`：枝條可指定母枝。
- `build_trees_b.py`：B 批樹種登錄。
- `preview_trees_b.py`：取景比例依樹的高與寬放大；TR01／TR02 比例仍是 1。
- `tr_broad.py`：新檔，`SHADE_UP` 只有 TR07 用。
- `tr_tex.py`：圖集空白處的填色可選（`ATLAS_BLANK`），只有 TR07 用。

## B 批保守做法與已知問題（寫進 PR）

- **顏色：** 楓「紅要沉」、銀杏「金要舊」照工作包最保守的讀法，調到在 Unity 裡仍是暗紅、舊金；之前問過的配色問題沒有答覆，照這個做。
- **TR07：**
  - 只做花期：花團點綴、偶爾嫩葉，不做滿樹葉。工作包只寫花，這是最保守的讀法。
  - 枝條轉折偏硬，少數細枝在樹冠裡交叉。
  - Blender 審圖（Cycles）裡，樹冠內側的花偏黑：小花卡很密，互相遮擋，預覽環境光又弱。Unity 截圖裡同位置的花是淡色的，花色以 Unity 截圖為準。
- **TR06：**
  - 垂條長度上限 7.5 m，0.35 m 以下的段不建，不拖地。
  - 頂點色 B（高度）照全樹高寫，垂條下段高度小，若 shader 用高度乘擺幅，下段擺幅會被壓小；擺動權重 R 已補償（下段 1.0）。
- **TR04：** LOD1／LOD2 卡數相同（末梢節點少於 LOD1 配額），面數仍在上限內。
- **TR05：** C 款 LOD0 葉卡 7,769 張，略多於設定的 7,400，因為 C 款的葉量係數是 1.05（老樹冠較大）；面數 24,444 仍在 25,000 內。
- **TR03：** 受光面略偏薄荷；主幹頂與大枝交接處有一圈接縫，近看才看得到。
- **三視圖：**
  - 所有候選圖根部的石頭、草、水和樹上的布條、木板都不建。
  - 樹皮比例照真實樹種，不照圖量。
- **未驗：** 正式場景擺放（In-game Verified）、手機效能、光照烘焙、遮擋剔除、大量種植。不宣稱 FPS。
