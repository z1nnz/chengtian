# SS01｜半埋踏石

- 參考：`art/references/core-d2-models-v1/SS01/turnaround.png`。建模前重看三種石塊的透視、側面與俯視；選用理由是同張圖可對出長方、近方與近圓三種輪廓，也清楚顯示磨平頂面、較粗的側壁，以及苔集中在邊緣。D2 的 V2、V3、V5 確認它們應半埋在泥路，不排成整齊石階。
- A／B／C 各有獨立 `.blend`、FBX（LOD0–2）、GLB（LOD0）、1024 像素貼圖、四視角、線框、1.75 m 人形尺和並排預覽。`model_info.json` 收錄各變體尺寸與面數。
- 匯出 pivot 在石塊底部；安放時底部埋入泥路約 0.06 m。未在 Unity 場景中檢查地面接縫、實際光照或手機效能。
