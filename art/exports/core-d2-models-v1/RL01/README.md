# RL01｜苔蕈朽木

- 參考：建模前重看 `art/references/core-d2-models-v1/RL01/turnaround.png`。選用理由是同一張三視圖清楚分出 A 的長木、B 的斷開腐空，並標出掀起的木纖維、剝皮、背光側苔及木身上的傘菇與檐菇；側視和俯視可核對端面、木徑與生長位置。D2 V5、V6 補充林下濕暗色階與路側擺放環境。
- A 為長朽木，B 為斷成兩段的腐空朽木。兩種都有裂紋樹皮、剝落材質區、破裂木片、苔、褐蕈及可見的腐空端。長度約 5.03／3.89 m；A 比 5 m 上限約多 3 cm。
- 原始 `.blend` 與重建腳本：`art/source/core-d2-models-v1/RL01/`。每種 FBX 含 LOD0–2，GLB 含 LOD0，`Textures/` 為 2048 像素烘焙圖集。
- Blender 5.2.2 game QA 兩種均 0 錯誤；FBX 與 GLB 已回匯確認。警示為嵌入木身的檐菇背面與少量完全內包的小件，表面無重疊或游離網格。`art/previews/core-d2-models-v1/RL01/` 有四視角、線框、1.75 m 人形比例與同相機、同燈光、同背景的 AL01 並排圖。
- 相較 AL01，木身材質與破裂輪廓在同距離可讀，但苔、碎葉與蕈的堆積層次仍比選定三視圖簡化。尚未在 Unity 地形上擺放或驗證接地與手機效能。
