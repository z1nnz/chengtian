# CO01｜被挖的坑

- 參考：`art/references/core-d2-models-v1/CO01/turnaround.png`。建模前已重看四視角；選用理由是同一張圖同時交代坑口俯視輪廓、約 0.6 m 的側壁深度、翻土偏向一側，以及碎石、跨緣斷根和淺色新斷口的位置。D2 的 V4、V6 確認它在林地中應有不規則土沿。
- 尺寸約 4.8 × 4.8 m。坑底在地表下約 0.6 m；匯出 pivot 位於模型最低處，場景安放時需下移約 0.68 m，並在地形切出約 4.6 m 的開口，讓外緣與地表銜接。
- 原始檔與重建腳本：`art/source/core-d2-models-v1/CO01/`。FBX 含 LOD0–2；GLB 含 LOD0；`Textures/` 是烘焙圖集。
- 幾何包含連續坑底與土壁、偏側翻土、半埋碎石、三條有淺色斷口的根及少量苔塊。未在 Unity 場景內安放或驗證地形接縫。
