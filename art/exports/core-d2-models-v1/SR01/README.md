# SR01｜地表盤根

- 參考：`art/references/core-d2-models-v1/SR01/turnaround.png`。建模前重看三種根形的透視、側面與俯視；選用理由是同張圖明確顯示長短差異、拱起高度、兩端埋土及側枝分岔，能直接對照道路跨根的需求。D2 的 V2、V3、V5 確認盤根應與濕泥路、巨樹板根相接。
- A／B／C 各有獨立 `.blend`、FBX（LOD0–2）、GLB（LOD0）、1024 像素貼圖、四視角、線框、1.75 m 人形尺與並排比較預覽。`model_info.json` 收錄尺寸與面數。
- 兩端與分枝末端在地表收束，場景安放時需讓它們和泥土、板根自然銜接。尚未在 Unity 實景檢查道路跨越、地面接縫或手機效能。
