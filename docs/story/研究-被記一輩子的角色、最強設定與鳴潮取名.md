### 歸納：被記一輩子的十個手法
1. **一個定義一生的選擇**（芙寧娜演戲、艾斯擋拳、碧瑤擋劍）。
2. **重擔藏在表面底下**：好笑、浮誇、冷漠、天真的外表，底下是最重的事。
3. **一句話成為別人的信條**（煉獄「燃燒你的心」）。
4. **知道自己被愛著**（艾斯）。
5. **最強的人也守不住**（緣壹、五條）。
6. **天真的人被當成武器**（繪梨衣）。
7. **理想對、手段錯的反派**（夜神月）。
8. **很早就死的前輩**，死得越早，後面每一章越想他（煉獄、水門）。
9. **一個物件承載他**（繪梨衣的小本子、艾斯的帽子）。
10. **每個人的感覺都不一樣**：燃（煉獄）、痛（艾斯）、怕（夜神月）、心疼（繪梨衣）、釋然（芙寧娜）。

## 二、「最強」的設定怎麼做

看五條悟、白鬍子、緣壹、卡皮塔諾、荒天帝、阿良歸納：

| 規則 | 說明 |
|---|---|
| 1. 最強是全世界的座標 | 所有人用他當標準：「那個人還在，天就塌不下來。」 |
| 2. 很少出手，出手就是大事件 | 平常在掃地、喝茶、睡覺；一出手，整個世界都知道 |
| 3. 最強也有代價或限制 | 孤獨、壽命、誓言、不能離開某個地方 |
| 4. 最強倒下，是整個故事的轉折 | 他一倒，所有人的安全感跟著倒 |
| 5. 最強也有打不贏的東西 | 天、時間、自己的心 |
| 6. 用別人的反應襯托 | 不直接寫他多強，寫強者見到他時的反應 |
| 7. 最強要用來扛別人 | 被記住的最強，都是守護別人的那一個 |

### 《承天》的戰力天花板（建議）
| 層 | 誰 | 說明 |
|---|---|---|
| 天外 | 殼外那個東西 | 不能用「打贏」解決，只能一起撐住 |
| 天 | 天道 | 七千年一個人在殼上拔河 |
| 古今第一人 | 師父（大乘） | 七道歸一，世上最後一個走完承天道的人；全世界的座標：「當年有他在」 |
| 現世最強 | 冰輪（體道，緘） | 閉口三百年，從不出手；他一出手是終章 |
| 天下第一劍 | 銀鉤（劍道） | 三百年沒出劍，江湖仍說「天下第一劍在既望的洞裡」 |
| 傳說 | 登天者 | 七千年前第一個穿過天的人 |

另外在世界裡設一張「**人間榜**」（不叫飛升榜）：
- 列出現在最強的十個人，裡面有幾位是三百年前的七人，用的是江湖傳言的名字，玩家不知道是誰；
- 玩家一路聽到這張榜，越往後越知道榜上是誰；
- 榜首寫著「冰輪」，沒有人見過他出手。

## 三、鳴潮的取名方式

| 角色 | 取名邏輯 |
|---|---|
| 角（今州的歲主） | 東方蒼龍七宿的第一宿「角宿」：地區之神用星宿命名 |
| 今汐（今州令尹） | 「今」是今州、「汐」是潮汐（遊戲叫鳴潮）；被歲主救活的嬰兒，以地名命名 |
| 長離 | 「長離」是鳳凰的古稱（《楚辭》），她用火 |
| 相里要 | 複姓「相里」是墨家的一支，墨家擅長機關；他是工程師 |
| 椿 | 《莊子》「大椿」，以八千歲為春、八千歲為秋，長壽 |
| 卡提希婭、珂萊塔、坎特蕾拉、露帕、菲比、英白拉多（黎那汐塔） | 用義大利、拉丁文：坎特蕾拉（Cantarella）是傳說中波吉亞家族的毒藥；露帕（Lupa）是羅馬的母狼；英白拉多（Imperator）是皇帝的稱號；菲比（Phoebe）是光明、月亮 |

**方法**：
1. 名字跟著地區的文化走（今州中文古典，黎那汐塔義大利、拉丁文）；
2. 名字直接藏著角色的職業或能力（相里＝機關、坎特蕾拉＝毒、長離＝火）；
3. 地區之神用星宿、古代稱號；
4. 中文名多用古典裡的別稱（長離＝鳳凰），一般人一眼看不出來，查了才懂。

### 用在《承天》
- 我們的「七人合起來是一輪月」，跟鳴潮用星宿替歲主命名是同一種做法（一個天文體系對應一群人），可以保留。
- 七人的本名可以照鳴潮的方法：**本名藏能力或職業，出處跟著古國走**。例如：
  - 丹道（羽衡，埃及）本名取埃及的醫神或生命之鑰；
  - 器陣（版築，兩河）本名取建塔的人；
  - 靈道（金穗，馬雅）本名取與獸、玉米有關的英雄；
  - 體道（桑榆，希臘）本名「緘」，字根是希臘語的「承受」（已定）。
- 鼇極（青溪）人用中文古典別稱，像長離＝鳳凰那樣：
  - 劍道「江柳」；
  - 茶亭「江梅」；
  - 師父「江承」。
- 七地的守柱者、地方之神，可以用該地文化的天文名字。
