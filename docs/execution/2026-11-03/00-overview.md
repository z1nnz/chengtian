# 11/03 工作包總表｜誰做什麼，不做重複的東西

> 2026-11-02，Claude Code（核心組）依 z1nnz 指示撰寫：「把其他人的包也一起做，不要讓他們做重複的東西」「他們之前做過的工作包都有紀錄，我要做新的東西」「工作量大概 28 小時」。
> 內容從故事（第一章大綱、第一章故事詳細版、故事定稿）和遊戲安排（總覽、遊戲整體架構）找缺口，不自己加故事和安排裡沒有的玩法；也對過 `docs/execution/` 裡所有舊工作包、Codex 工作單和 `art/` 裡的模型。開工前先看這一頁。美術標準和 AI 提示詞照 [美術風格指南](../art-style-guide-v1.md)。

## 0. 這一輪的方向（z1nnz，2026-11-02）

- **以建模為主，把世界建得好看**。玩法只留非常必要、能讓我們測試好不好玩的。
- **模型要照[畫質分級](../../standards/quality-tiers-v1.md)交**：同一份模型，手機、網頁、電腦看到的細節不同。
- **人物先不上工作包**：人物的故事、名字、誰會出現都還沒定。不放人物、人物的教學、人物專屬道具，也不寫死台詞。
- 內容從故事和遊戲安排找缺口，不自己加安排裡沒有的玩法。

## 4. 哪些東西不嫌多

這幾類世界越大越需要，可以同類很多件，但**每件要有自己的外形**，不要只靠旋轉、縮放、換色，也不要和第 3 節的東西長得一樣：灌木和地被的新品種、石頭的新形狀、不同人家的生活小物、賣不同東西的攤位。工作包做完還想多做這幾類，直接做、照規則交，寫清楚是額外的。
