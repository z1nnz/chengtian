## 1. 所有畫面都要遵守

### 1.1 視角

- **玩家眼高 1.6 m，鏡頭約 50–60°**，除非表格寫明是俯瞰。站在玩家真的走得到的位置。
- 畫面要做得出來：不要畫遊戲裡走不到的地方當主體，也不要畫現有模型做不到、又沒有人排工作的東西。
- 大小要對：畫面裡的門高約 2.2 m、人高 1.75 m。**不要把開闊的山谷畫成一個小碗**，這是這條流程最常見的失敗。

### 1.2 構圖：每張都要有三層

| 層 | 內容 | 距離 |
|---|---|---|
| 前景 | 看得清材質的東西：草、石、欄杆、小物 | 5 m 內 |
| 中景 | 這個地方的主角（地標）和一條看得出能走的路 | 15–60 m |
| 遠景 | 下一個想去的地方、遠山、霧 | 100 m 以上 |

**看一眼就要知道路往哪走，以及遠方有什麼值得去。**

### 1.3 顏色和光

- 用 [`modeling-style-spec-v1.md`](../../art/modeling-style-spec-v1.md) 第 2、11 節的色票。
- **絕對不要現在遊戲裡的螢光綠和塑膠感**。植物綠是 `#4E6B3A`、`#6F8A4A`、`#2F4A2A`。
- 靈氣只用青、金、月白，面積 ≤ 5%（河谷更少）。
- 對齊 `art/references/world-vision-v2/` 五張方向圖的層次和飽和度。璃月是**製作水準和規劃方法的參考，不要照抄**它的建築、地標或地圖，也不要做成日式。

### 1.4 不要有

人物（遠處小剪影也不要）、文字、招牌字、數字、UI、浮水印。

### 1.5 每個畫面要交的東西

放在 `art/references/keyart/<畫面ID>/`：

| 檔案 | 內容 |
|---|---|
| `candidate-1～4.png` | 同一段提示詞至少四張，16:9 |
| `chosen.png`、`prompt.txt` | 選哪張、為什麼 |
| `zone-map.png` | 俯視分區圖：路、地標、水、玩家走法，用區塊實際座標 |
| `atmosphere.md` | 時間、太陽方向、主光和陰影色碼、霧的顏色和距離、風的感覺 |
| `parts.md` | 畫面裡每樣東西：已有哪個模型（寫路徑）、還缺什麼、由誰做 |

### 1.6 怎麼算做到

進遊戲後，在同一個位置、同一個鏡頭截圖，和主視覺**左右並排**存成 `art/previews/keyart/<畫面ID>/compare.jpg`：

- 灰模階段：主要形狀的位置和大小對得上，放 1.75 m 人形尺比。
- 成品階段：遮住文字看，兩張要像同一個地方；不要求每個像素一樣。
- 對不上時**修場景，或回頭改主視覺**，寫清楚改了哪個；不要假裝一樣。

## 3. 走一遍的節奏（區塊之間要順）

玩家從官道一路走，畫面要這樣變：

| 路段 | 變化 |
|---|---|
| 官道 → 村口 | 開闊變得有人氣；看到古樹（第一個地標） |
| 村 → 西溪 | 房屋變少，水聲變大，材料變成石和濕木 |
| 村 → 東坡 | 一路往上，視野打開，第一次看見山城 |
| 村 → 古林 | 光變暗、樹變大、沒有房子，顏色變深 |
| 古林 → 山門 | 樹變少，石頭變多，開始出現整齊的人造石階 |
| 山門 → 山城 | 從冷清變擁擠，從自然變莊嚴 |

區與區之間留 30–60 m 過渡帶（規格第 11.3 節）：植被、材料和顏色慢慢混，不要一條線切開。**每個路段轉彎處都要能看見下一個地標**，這比多擺模型重要。
