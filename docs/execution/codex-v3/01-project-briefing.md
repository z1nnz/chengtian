# 《承天》專案簡報｜故事、遊戲、現在的進度（給 Codex）

> 2026-11-03，Claude Code。讀完你要知道：這個遊戲在講什麼、玩家做什麼、世界長什麼樣、做到哪裡了、誰在做什麼。**你的模型擺進去之前，要先知道它為什麼在那裡。**
> 這份是濃縮。細節以下面第 8 節的文件為準。

## 1. 一句話

**月亮擋著通往仙界的通道，通道裡蹲著吃人的域外來客。三百年前月食那一夜，月亮暗了；一個女子化成缺了一角的月亮，撐到今天。各方都想救月亮，手段一個比一個狠。玩家這一代，要和所有人一起把月亮補圓。**

- 遊戲名《承天》。世界「不周」（有缺口的世界）。新手地區「鼇極」，新手村「青溪村」。最高處「雲境」，在月亮正下方。內部代號還叫 YunJing，檔案裡看到雲境／YunJing 是同一個專案。
- 手機優先的多人修仙生活 RPG，Unity 6000.0.82f1＋NestJS，**伺服器說了算**。主力是瀏覽器 PWA，其次 Windows，之後 Android。
- 美術目標：以《原神》璃月的完成度為底線，要更好看；學原理，**不抄**任何受著作權保護的建築、圖案、標誌。

## 2. 世界規則（影響你做的東西）

| 東西 | 是什麼 | 對美術的意思 |
|---|---|---|
| 月亮 | 通道口的保護層。三百年前起**缺一角、不動**，掛在雲境正上方，從哪裡看都在同一個位置 | 你第 1 天要做的第一件東西。這不是裝飾，是整個故事的中心 |
| 天柱 | 七根，把各道統的力量送上月亮 | 這三包不做 |
| 天劫 | 禁制在攔想飛升的人 | 這三包不做 |
| 濁氣、濁獸 | 通道滲下來的黑氣，把動物染黑。打倒就是淨化 | 黑紫色、墨滲感，不是魔物 |
| 飛升榜 | 世人供奉歷代飛升者的榜，最後一行空了六十年。**玩家一開始羨慕它** | 第 3 天。要讓人嚮往，不能看起來陰森 |
| 高塔 | 太玄道院把人送進去的地方。玩家很久以後才懂 | 第 3 天。**乾淨、莊重、太高太冷，不是邪惡的黑塔** |
| 青溪 | 斷了靈脈的邊陲，空屋很多，溪停了 | 溫暖、有人住，但看得出人變少了 |

**時間線**：同承紀（一萬年前，月亮圓、會走）→ 登天之變（七千年前，遊戲序幕）→ 七國紀（七國建天柱）→ 長夜（兩千年前）→ 宗門紀（十四宗）→ 仙凡之戰（八百年前）→ 斬天之夜（三百年前，全故事的核心）→ 戊辰年（六十年前）→ 現在（又是戊辰年）。

**沒有真正的壞人**：每一方都想救世界，手段一個比一個狠。**真相要很久以後才揭開，新手十天是溫暖的**，做東西不要提早流露悲劇感。

**七地**（之後的大版本，這三包不做）：金穗（馬雅、靈道）、羽衡（埃及、丹道）、版築（兩河、器陣道）、祇苑（印度、法道）、桑榆（希臘、體道）、既望（日本、劍道）、九夜（北歐、冥道）。

**人物**：詳見第 8 節的文件，讀了可以知道感覺。但**名字、故事、誰出現都還沒定**，不要做進資產。

## 3. 玩家的十天（序章）

一天解鎖一件事。沒上線就等著，不懲罰。感覺是溫暖、日常。

| 天 | 發生什麼 | 場景 | 這天的東西到位了嗎 |
|---|---|---|---|
| 1 | 走官道到茶亭、喝茶、拿梅苗和小燈、分到空屋、種梅、第一次看見不動的月亮 | A2、A1、領地 | 流程有；茶亭模型在 PR #60 剛合併；**月亮沒有**（你 D1） |
| 2 | 院子開田；練體；村口夜裡第三盞燈 | 領地、A1 | 練體課和靈田已合併 |
| 3 | 上游看溪為什麼停；溪邊溫的石頭；濁化山豬 | D3 | 石壩、溫石、山豬已合併 |
| 4 | 第一次收成、賣到坊市；學引氣 | 領地、A1 坊市、聽風台 | 玩法已合併，還沒接進主場景（核心組） |
| 5 | 去**山城**送東西，看到飛升榜、大鐘、街市 | B | **山城幾乎沒有**（你 D3；攤位是 B 做） |
| 6 | 選修水路的方法 | A1 | 現在只有對話 |
| 7 | 修水路；古林的碑上有一行被鑿掉 | A3、D | B 正在做玩法；C 正在做碑 |
| 8 | 水回來，流過每一戶田 | A3、A6 | B 做水路；**田和大水車沒有**（你 D2） |
| 9 | 在溪邊約定明年回茶亭 | A3 | 演出由核心組 |
| 10 | 上山城測資，有人被帶上高塔 | B2 | 廣場有；**高塔沒有**（你 D3） |

之後是第一章（入宗門、巡山、第一次渡劫……），再來七地各章。**現在只做新手大世界，先把青溪河谷做完整，再往外。**

## 4. 遊戲怎麼玩

| 玩法 | 內容 |
|---|---|
| 領地 | 每個新人從第一天就有自己的舊宅和後院（獨立小場景，推門進出）：種靈草、練功、閉關、佈置、博古架收藏 |
| 大世界 | 共用、連線、分線；探索、採集、狩獵、見聞與機緣、世界事件 |
| 修煉 | 境界：練氣 → 築基 → 金丹 → 元嬰 → 化神；十四宗、七道統 |
| 生活技藝 | 種田、煉丹、泡茶、煉器、畫符、佈陣 |
| 戰鬥 | 即時動作，比原神簡單：普攻、兩三招、閃避、一件法寶。最多四人 |
| 機緣 | 見聞（人人有）、個人機緣、限量、唯一；**機緣和隱藏點永不標示** |
| 晝夜 | 照現實時間，已上線（`QingxiDayNight`）；有些東西只在夜裡出現 |
| 付費 | 只賣好看，不賣變強，沒有抽獎 |

**空間**：領地（獨立場景）、大世界（每塊 100 × 100 m 區塊串流，45 m 載入、90 m 卸載）、宗門、秘境。
**推門就換場景**：建築的室內是獨立場景，外觀不用做室內。
