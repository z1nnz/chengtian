# 第二部分：要定的主要玩法

## 為什麼感覺在亂做（Claude Code 的診斷）

1. **沒有一頁寫「這遊戲主要玩什麼」**。總覽第六節把所有玩法平列：修煉、種田、煉丹、煉器、畫符、佈陣、探索、靈獸、秘境、宗門、對戰、機緣、大事件……沒有主次。
2. **玩法是從每天的劇情長出來的，一天一個小遊戲**：第 1 天泡茶、第 2 天練體、第 3 天打山豬、第 4 天收成賣貨。每個都用心做了，但沒人回答「玩完這個，我為了什麼再玩下一個」。
3. **做好的玩法大多還是各自獨立**。多數是展示場景或本機規則，還沒接進同一個世界、同一份背包、同一條成長線。把交件擺進世界，目前也只做到靜態模型。
4. **最上層的鉤子是舊世界觀**：`game-structure-v1` 的一句話還是「種靈草把世界縫回來」（脈息）。世界觀改了，玩法的「為什麼」沒跟著改。

## 要和 z1nnz 討論的題目

每題都要給選項。下面的【建議】是 Claude Code 的起點。

### C1. 這遊戲的一句話主玩法是什麼？

- A：**修行與生活**：把自己練起來、把家和村子經營起來，慢慢走遍世界。
- B：**動作戰鬥**：打怪、Boss、秘境、裝備。
- C：**開放世界探索**：走遍大世界、解謎、找機緣，像《原神》的探索。

【建議】A 為主、C 為輔，戰鬥只要順手。理由：團隊小、以建模為主、十天的節奏和生活系統已經是這個方向；硬拚動作戰鬥比不過大廠。要請 z1nnz 想：**他最想讓玩家截圖分享的是哪個時刻？**

### C2. 一條成長線：所有玩法餵給什麼？

現在的成長線有資質、修為、技藝、收藏、脈息、真相六條，太散。

【建議】用**「專精」**當主線，因為它剛好接上 z1nnz 的新設定：

> 玩什麼就練什麼 → 練到專精 → 身體裡出現缺月之力 → 終章全服一起補月亮。

玩家走自己的路（劍、丹、種田都算），這條路最後真的和世界的結局有關。**這句話可以取代舊的脈息鉤子**，但要先定 B1。這只是建議，z1nnz 可能有更好的。

### C3. 玩家一次上線 30 分鐘做什麼？

文件已有「回家 → 出門 → 回家」。要定具體版本，寫成一張時間表：進遊戲先做什麼、為什麼出門、帶什麼回來、今天結束時期待明天什麼。

【建議】收成補種（5 分）→ 練功或一項技藝（5–10 分）→ 出門探索、採集、打怪（10–15 分）→ 回家做東西、擺收藏（5 分）→ 留下明天才熟的東西。

### C4. 每個玩法留、併、還是砍？

做一張表，每一項回答：在 30 分鐘裡的哪一段？給玩家什麼？餵給哪條成長線？好不好玩測過了嗎？

| 分類 | 意思 |
|---|---|
| 核心 | 每天都會做，要做到最好 |
| 輔助 | 有空才做，給變化和感情 |
| 一次性 | 劇情演出，玩過就好（例如第 2 天的第一堂課） |
| 之後 | 先不做 |

【建議的起點】核心：種田收成、練功、探索採集、基礎戰鬥。輔助：煉丹、泡茶、販售。一次性：修水路（序章大事）、山豬遭遇。之後：煉器、畫符、佈陣、靈獸、宗門對決、爭奪秘境。**只是起點，要 z1nnz 拍板。**

### C5. 測得出好不好玩的最小版本是什麼？

現在沒有一個人能從第 1 天玩到第 10 天的版本。

【建議】先定一條「能玩完的一條線」：第 1–4 天接進同一個世界、同一份背包，存到伺服器，用手機瀏覽器讓 z1nnz 和協作者實際玩一週。**先把已有的玩法接起來，再做新的。** 問玩的人三題：想不想明天再回來？為什麼？哪裡最無聊？

### C6. 多人要多早？

文件順序是一個人玩得完整以後才做多人。要和 z1nnz 確認：序章要不要有其他玩家？什麼時候看得到彼此？這會影響「每個人自己的溪」那一整段規則。

### C7. 美術和玩法怎麼分工？

z1nnz 11/02 定「以建模為主，玩法只留必要的」。今天又說怕亂做。要確認：**建模照常全速，玩法只接不新做**，是不是 z1nnz 要的？
