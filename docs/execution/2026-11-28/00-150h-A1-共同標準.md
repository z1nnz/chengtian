## 七、每件都要交的東西

| 項目 | 規定 |
|---|---|
| 參考圖 | 先看概念圖；需要單件的三視圖或細節圖，**請 Claude Code 在 ChatGPT 出**（在 PR 或信裡寫要哪一件） |
| 對圖 | 每件交一張「成品渲染 vs 概念圖裡同一個東西」的並排圖，同光、同角度 |
| 形狀 | 中低頻的起伏做在幾何上，不靠貼圖畫；木頭有使用痕跡、石頭有磨圓和缺角 |
| 貼圖 | 一般件 1024；房子、涼亭等比人大的件 2048。Albedo／Normal／ORM／MaskURP。可以用 Poly Haven 的掃描材質（CC0）當底 |
| LOD | LOD0 不刪細節；LOD1 約 50%；LOD2 約 15%；照 `docs/standards/quality-tiers-v1.md` |
| 碰撞 | 走得到、會擋路的件要有碰撞殼；房子門可以先不開 |
| 比例 | 預覽圖放 1.75 m 人形尺 |
| 文件 | `model_info.json`、README（開頭照 `docs/standards/labeling-v1.md` 的表頭，寫實際工時、外部素材與授權） |
| 原點 | 底部中心、z = 0 在地面 |
