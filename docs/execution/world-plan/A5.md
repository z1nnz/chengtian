# A5 河灣渡口：從熟悉河谷望向外海

A5 佔世界座標 `x=-150～-50`、`z=-150～-50`，單位公尺，`+Z` 北。[A5-plan.png](A5-plan.png) 是 `100×100 m`、每格 `10 m` 的俯視配置；圖上 `30` 個編號與 `blocks/A5.json` 的 placements 一致。這個工作樹缺 KA05 主視覺與同鏡位遊戲圖，以下前中遠景屬施工圖與地形推導的規劃，待 KA05 入庫對圖。

## 玩家感受與路線

從 A3 南緣的溪與釣魚區接 A5 北口 `(-106,-50.5)`，玩家沿寬 `2 m` 小路抵 `(-95,-68)`，先聽水流展寬，接著在 `(-97,-80)` 踏上木棧橋。八段 FE01 由 `(-97,-80)` 先向北到 `(-97,-74)`，在 `(-98,-72)` 向西轉，末端 `(-104,-72)`；折線長約 `15 m`，FE02 船繫在 `(-109,-72)`，隔霧只見輪廓。玩家可在末端停看西南遠湖，也可回到岸上的小棚 `(-90,-82)`，沿官道路口 `(-50.5,-90)` 回 A2。另一條寬 `1.8 m` 的蘆葦路從橋基 `(-97,-80)` 到 `(-115,-101)` 的淺灘觀景點；蘆葦與柳樹成叢，保留棧橋和兩條路的淨空。

原 A5-S1 鏡位 `(-100,-70)`、yaw `225°` 位於河道與橋旁，無法沿橋看船；規劃鏡位調至 `(-98,-78)`、yaw `315°`，眼高 `1.6 m`、水平視角 `55°`，讓橋板從腳下引到船。A5-S2 `(-75,-90)` yaw `290°` 看蘆葦後的小棚；A5-S3 `(-105,-60)` yaw `90°` 從溪岸回望村方。鏡位調整須等 KA05 核對，現階段不能稱同角度對圖完成。

## 地形、道路、模型

北界 `(-110,-52)` 高 `0.9 m`，對 A3 南界 `(-110,-49)`；東口 `(-52,-90)` 高 `2.2 m`，往西濕地 `(-120,-85)` 降到 `0.35 m`，西南 `(-145,-95)` 為 `0.4 m`。`noise=0.15`、`relief=0.75 m`、`cliffs=0`；橋基 pad `(-97,-80)` 高 `0.8 m`，棚 pad `(-90,-82)` 高 `1.0 m`。岸路從 `(-50.5,-90)` 經 `(-75,-90)`、`(-90,-82)` 到橋基，寬 `2.2–2.4 m`；棧橋上玩家淨寬目標 `2.2 m`。

JSON 的 `creek` 以 A3 末端相同寬 `4.5 m`、挖深 `1.0 m`、岸寬每側 `3 m`、水位參數 `0.6 m` 接入，再由 `(-110,-60)`→`(-112,-68)`→`(-121,-75)`→`(-134,-85)`→`(-148,-96)` 出西南界。生成器目前只有固定 `width`，因此 `(-121,-75)` 開始展到 `18 m` 的河灣水面屬程式請求；不能把一條 `4.5 m` 溪叫做湖。`14` 叢 CO04 在橋側 `(-101,-77)`、`(-94,-74)` 與 `(-116,-57)` 到 `(-103,-84)` 的水邊分群；FI01–05 共 `5` 件在棚與橋基 `(-94,-85)` 至 `(-88,-86)`，沒有沿路平均撒。柳樹指定 `(-55,-60)`、`(-123,-55)`、`(-118,-111)` 三棵；最高的東北高岸留單棵高 `10 m` 柳樹。
