# D4 苔石古祠：林中被遺忘的一行字

世界座標單位為公尺，`+Z` 北；D4 範圍 `x=-150～-50`、`z=150～250`。[D4-plan.png](D4-plan.png) 每格 `10 m`，圖上 `32` 個編號與 `blocks/D4.json` 的 placements 一致。工作樹沒有 v8 指定的 KA12 `chosen.png`、氛圍卡與同鏡位遊戲圖，以下構圖依施工圖 `feel`、`zones`、`shots` 規劃，須待 KA12 對圖。

## 感覺與動線

玩家從 D2 西口 `(-49.5,214)` 接 D4 東口 `(-50.5,214)`，沿 `2.2 m` 舊土石路經 `(-72,211)`、`(-88,205)` 走向高台 `(-100,200)`。D4-S1 `(-78,196)`、yaw `275°` 先看見前方兩個倒伏石燈 `(-87,201)`、`(-95,196)`；林隙後，祠的北牆與西牆才逐漸露出。祠東與南保持敞開，玩家不用繞不可見的牆。踏上 `16×14 m`、高 `13.5 m` 的石台後，在 D4-S2 `(-98,195)`、yaw `0°` 停下，近距離看 `(-100,202)` 古碑的缺月記號；`(-101,198)` 的殘香爐與斷供桌在碑後偏左。

三面苔石坡圍出中央高台，外圈柏林成叢而非均勻撒樹。祠心 `(-100,200)` 半徑 `10 m` 的路與觀碑位置保持通透；西南高丘 `(-138,162)` 留 `1` 棵高 `10 m` 的單樹供遠處尋視。舊路只有東側入口，西、北、南坡可以步行探索，但不加第二條明顯官道。
