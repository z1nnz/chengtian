## 3. B 部分：依圖重做 D2 佈局

1. 讀 `D2-inventory.md`。看著你的六張圖核對：圖裡有、清單沒列的東西，寫進 `docs/execution/world-plan/D2-inventory-notes.md`（東西、出現在哪張圖、大約幾件）。
2. 重寫 `tools/qingxi-terrain/blocks/D2.json` 和 `docs/execution/world-plan/D2.md`、`D2-plan.png`：
   - 清單裡每一種物件都要有落位，件數接近清單（總數 700 件上下）。缺的模型照樣給座標，`status: "missing"`。
   - 大型和中型（約 160 件）逐件寫 `placements`。
   - 小物和樹用**聚落**寫，不要一件一件列：新增頂層欄位 `clusters`，每筆 `{ id, x, z, radius, items: [{ model, count, scaleMin, scaleMax }], yaw: "random"|"outward"|"alongPath", avoidPath: true, note }`。每個地標、每段路邊、每個停留點周圍都要有聚落。（程式之後會由 Claude Code 或你在整合輪展開。）
   - 六張圖的相機寫進 `shots`（位置、朝向、時間），之後同鏡位對圖用。
   - 地形高低要和 V1 一致；和 D1（南）、D4（西）、D6（東）、D7（北）的邊界高度和路要接上。
3. 在 `D2.md` 最後加一張表：六張圖各自「畫面裡的東西 → 對應哪些 placements／clusters」，讓人能核對佈局真的照圖。

## 4. 驗收

1. 六張圖是同一個地方（地標位置關係一致）。
2. 佈局總件數 ≥ 600，種類 ≥ 45；每一筆有座標和數值。
3. JSON 欄位和型別正確（`clusters` 是新增欄位，其他照 `QingxiVillageTerrain` 的定義）。
