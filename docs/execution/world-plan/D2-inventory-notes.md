# D2 六視圖對物件清單的補充

以 `D2-inventory.md` 第零節為準核對 V1–V6。該節已收錄圖中新增的入口大根拱、踏石、闊葉植物、根洞、上坡石階、水窪、根上藤葉與褐色蕈；本輪未發現須另外增加的物件種類。

佈局把神木本體與放射板根視為同一組待交付模型，但另以八個 `BUTTRESS_ROOT` 座標記錄板根走向，供建模與整合時核對；這八個定位點不代表可以用舊根件代替。V6 近景的翻土、斷根、白花、積水、苔與碎石皆已落在坑緣 `placements` 或 `d2-floor-pit`、`d2-detail-pit-detail` 聚落。V1 的外圈松、東西出口和南入口則分別落在 `d2-forest-*`、道路節點及 `D2_FR02_001`。

圖中的光束、低霧、飄葉與林地地表屬程式或地形材質，不計入 906 件模型數；位置與需求記於 `D2.md`，待 B 階段實作及對圖驗證。
