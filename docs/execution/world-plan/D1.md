# D1 林緣獵場：從村北走向神木

世界座標以公尺計，`+Z` 北；D1 範圍 `x=-50～50`、`z=50～150`。[D1-plan.png](D1-plan.png) 為每格 `10 m` 的俯視配置圖，使用既有 `blocks/D1.json` 疊上 [D1-proposal.json](D1-proposal.json) 繪製。後者是**補完提案**，沒有寫入既有 D1 JSON；程式端須依 `code-requests.md` 合併並建置後才算落位。D1 沒有指定主視覺圖，施工圖只給三個鏡位，故以下構圖是待截圖核對的導演規劃。

## 感覺與行走節奏

從 A1 北界 `(12,49.5)` 接 D1 `(12,50.5)`，原有 `2.2 m` 土路向 `(4,72)` 走。`(12,72)` 一帶以六件兔徑地表和三段破竹籬讓人先發現獵場活動；走到分叉 `(4,72)`，西路至 `(-49.5,78)` 接 D3，東北路到 `(18,96)` 的瞭望台。瞭望台實位 `(22,104)` 高約 `6 m`，在此停下回望溪谷，正北先看到 D1 既有守脈古樹 `(-5,128)` 與七棵柏的輪廓。

北行新路從 `(18,96)` 經 `(25,120)`、`(25,141)` 到 `(10,149.5)`，全程 `2.2 m`；它走在既有七棵柏群東側，避開 `(8.2,135.2)`、`(5.9,126.7)` 的樹幹，最後接 D2 `(10,150.5)`。路兩旁 `(15,137)`、`(34,134)` 放 FR01 根牆，讓玩家先感到樹與根變大，才在 D2 見到 `90 m` 神木。D1-S3 `(10,145)` 朝北的路口必須保持 `2.2 m` 淨寬；不要把根牆堵在路心。

## 地形、物件與配置圖

既有 D1 南側 `(0,62)` 高 `2.4 m`、西側 `(-40,64)` 高 `2.6 m`，向北 `(−30,128)` 高 `7.5 m`、`(30,132)` 高 `8.0 m`；提案在 `(25,120)` 加 `7.1 m`、`(25,141)` 加 `7.8 m`、`(10,149)` 加 `7.9 m` 三個高度點，讓北路逐漸升高並接 D2 南緣 `7.9 m`。現有 `relief=3.0 m`、`cliffs=6.5 m` 對路側的實際坡度須出圖驗證，北路兩側 `2 m` 內不要形成斷崖。

提案有 `35` 筆 placements，其中 `1` 筆替換既有空槽；既有 SC04 獵人棚保留，疊圖總計 `36` 件。依施工圖 zone 件數：瞭望台 A10 `1`、警示架 A11 `1`、棚邊 R03 柴堆 `2`、山兔地表 A01/A07/A02 `6`、A03 倒木與 A06 樹樁 `6`、A08 破竹籬 `3`；額外依 fill 放 A04/A05 苔石 `12` 群，北路加 FR 根牆 `2`、FP 路件 `2`。每件的世界座標、yaw、占地、來源模型與碰撞均在提案 JSON，配置圖編號 `1–36` 可逐一查。`world-dressing.json` 的 D1 既有 `ElderCypress` 比重 `1.0`、`8` 棵敘事地標樹不改，以免重複種樹；叢林仍須保留南疏北密的密度變化，南側 `(0,60)` 周圍 `100 m²` 約 `1` 棵，北側 `(25,135)` 周圍 `100 m²` 約 `3` 棵。
