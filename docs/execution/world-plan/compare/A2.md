## 最影響觀感的前五項

1. 以 `(0,-118)`、yaw `0°`、眼高 `1.6 m`、視角 `55°`、`17:30` 重拍，排除目前鏡位和時段差異。
2. 讓茶亭 `(-18,-108.5)` 的屋頂進入畫面水平 `10–35%`；若遮擋，將 pad `(-17,-107)` 高度試到 `1.6 m`。
3. 於 `(7,-116)` 與 `(10,-118)` 形成板車和路牌的右前景，並維持官道淨寬 `3.4 m`。
4. 在 `(-11,-13)`、`(16,-18)` 放 `2` 道高 `6 m` 的炊煙；從 `(0,-118)` 能看見 `(0,6)` 古樹冠。
