# D6 古林深處往山腳：從樹影進入石階

世界座標單位為公尺，`+Z` 北。D6 是 `x=50～150`、`z=150～250` 的 `100×100 m` 區塊；[D6-plan.png](D6-plan.png) 每格 `10 m`，`27` 個編號對應 `blocks/D6.json` 的模型落位。v8 規劃書指定 KA13 為 D6，本工作樹沒有 KA13 圖和同鏡位遊戲截圖；已在施工圖 D6-S1 補 `ka: KA13`，下述構圖仍待對圖。

## 感受與視線

從 D2 東口 `(49.5,221)` 接 D6 西口 `(50.5,221)`，玩家沿 `2.4 m` 路逐漸上坡：`(72,219)` 約 `13.1 m`、`(100,213)` 約 `18.2 m`、`(122,202)` 約 `22.5 m`。D6-S1 `(100,195)` 向東 `85°`，先看到樹距拉開、岩石比蕨多，接著在 `(124,201)` 看見第一塊整齊的 TE03。八件 TE03 從 `(124,201)` 逐件上升到 `(147.8,198.2)`，高約 `22.8→28.4 m`；在界碑 `(140,198)` 停下來回望西側神木方向。D6-S2 `(135,195)` 向東 `80°`，讓石階收向 B1 山門方向；東口 `(149.5,200)` 地面目標 `29.5 m`。

前 `60 m` 的樹從 ElderCypress 過渡到 pine，`world-dressing` 比重 `0.55/0.45`，但分叢布置：`(65,215)` 周圍 `15 m` 仍以柏為主、`(130,215)` 周圍 `15 m` 以松和裸石為主。路和石階兩側各留 `2.4 m`；東北高丘 `(135,238)` 留一棵高 `12 m` 的柏樹作尋視點，離主階約 `40 m`。玩家可走到 `(110,232)`、`(134,180)` 等側坡岩石群，不用看得見卻上不去。

D2 東界 `(49.5,221)` 高約 `9.7 m`，D6 西緣 `(52,221)` `9.7 m`。地面從西向東升：`(72,219)=13.1 m`、`(100,213)=18.2 m`、`(122,202)=22.5 m`、`(140,198)=27.5 m`、`(148,200)=29.5 m`。北丘 `(145,245)=28 m`、南東角 `(148,155)=21 m`，讓後段較陡但路仍連續；`relief=1.1 m`、`cliffs=4.2 m`、`noise=0.2`。八個 `flats` 位於每段石階下方，半長 `1.4×1.4 m`，高度 `22.8、23.6、24.4、25.2、26.0、26.8、27.6、28.4 m`。石階 FBX 的實際底與朝向尚需 Unity 核對。
