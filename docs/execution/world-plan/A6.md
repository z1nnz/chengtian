# A6 稻田與大水車：通水後的河谷

本規劃採世界座標公尺，`+Z` 北；A6 範圍 `x=50～150`、`z=-150～-50`。[A6-plan.png](A6-plan.png) 每格 `10 m`，藍線為北渠，黃點為 `300` 株 RI02，棕點為 `32` 段 RI01 田埂；具編號者為水車、踏板與 `10` 塊田底座。圖和 `blocks/A6.json` 同由 [make-a6.py](make-a6.py) 的固定座標產生，重跑不會換田位或重抽稻株。

本工作樹尚無 KA06 主視覺 `chosen.png`、氛圍卡、物件表，也無 A6 同鏡位截圖。因此下列前中遠景和光是從施工圖的 `feel`、`shots`、`zones` 推出的**設計假設**；待 KA06 入庫及 Unity 出圖後再作對圖修訂。

## 感覺、入場與停點

玩家從 A2 東緣 `(49.5,-90)` 走到 A6 西口 `(50.5,-90)`，沿 `2.4 m` 路往 `(55,-76)`，先聞水、看見 `(95,-70)` 高 `9 m` 的 RI03 大水車；轉頭向南，`10` 塊不規則高低的水田在 `(65～113,-91～-114)` 鋪開。水車與田間有留出通行的西路 `x≈55 m` 和兩排中間 `z≈-102 m` 的 `1.8 m` 田埂路。玩家到 `(86,-108)` 沿稻田邊向北看水車，往 `(55,-102)` 轉進田間，再於 `(110,-125)` 向北回看水車剪影。東側 `(135,-105)` 暫留小廟 pad，未有模型前保持空地；踏板 `(125,-102)` 跨 `2.2 m` 水渠接東路。

施工圖原 A6-S1 `(95,-70)` 與水車中心重合，鏡頭會進入模型包圍盒；已將規劃點移到 `(86,-108)`、yaw `15°`，距水車約 `39 m`，使第 `8` 塊田的稻株在前景、水車在中景。A6-S2 `(60,-90)`、yaw `80°` 看整片田；A6-S3 `(110,-125)`、yaw `340°` 從田埂看北渠。三處皆按眼高 `1.6 m`、水平視角 `55°` 拍；等 KA06 補入再調鏡位。

## 地形、道路與水

地勢是平谷：A2 西接 `(52,-90)` 高 `2.3 m`，北端 `(95,-52)` 高 `1.6 m`，田心 `(90,-105)` 高 `1.5 m`，東側小丘 `(135,-52)` 高 `2.6 m`；`noise=0.12`、`relief=0.5 m`、`cliffs=0`。每塊田的 pad 半長 `4.6×4.1 m`，高度循環 `1.15/1.37/1.59 m`，相鄰水田形成 `0.22 m` 小差；田埂每段實際 `footprint` 見 JSON，通道以 `1.8–2.4 m` 為準。

北渠用 `creek` 欄位暫記：`(95,-50.5)`→`(95,-70)`→`(112,-79)`→`(123,-89)`→`(125,-124)`；寬 `2.2 m`、挖深 `0.7 m`、兩岸各 `1 m`、水位參數 `0.35 m`。`(125,-102)` 的 QX 踏板提供跨渠；不能讓 `a6-east-path` 直接踩水。A4 南邊尚無渠段，所以 `(95,-50)` 是**待接水源**，不可先宣稱通水完成。田底座 RI01、田埂 RI01、稻株 RI02、RI03 水車與 QX 踏板總計 `344` 件；`status: needs-importer`，尚未進場景。稻株 `300` 個落位需 GPU 實例及生長階段切換，JSON 不表達動畫時序。
