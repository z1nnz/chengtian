# D2 古樹神木：凹地與根間道路

本圖依 `world-blueprint.json` 的 D2 施工資料與 `blocks/D2.json` 作配置。世界座標單位為公尺，`+Z` 北，D2 範圍 `x=-50～50`、`z=150～250`。[D2-plan.png](D2-plan.png) 為 `100×100 m`、每格 `10 m` 的俯視圖；紅色點的編號對應 JSON 的 `placements` 順序，藍字是地形高度點。這份工作樹目前沒有 KA11 的 `chosen.png`、`atmosphere.md`、`parts.md`，也沒有 D2 的同鏡位遊戲截圖。以下構圖是施工圖指定的鏡位與感受所推導的**佈局假設**，仍須用 KA11 對圖，不能視為已驗收的畫面。施工圖原把 D2-S1 標成 KA08，已依 v8 規劃書的對應改為 KA11。

## 玩家感受與動線

玩家從 D1 北側 `(10,149.5)` 接 D2 `(10,150.5)` 進來，走 `2.2 m` 寬的土路，地面從約 `8 m` 逐漸降到神木中心 `(0,200)` 的 `4.8 m`。入口 `(10,167)` 的巨根弓把天空壓低；第一眼在 D2-S1 `(10,145)`、yaw `355°` 看見神木枝冠，眼睛先找樹幹，再被 `(9,178)` 的小停點引向根間道路。路在 `(11,194)` 經根上步道，向左到 `(4,205)` 的樹根下空地；往右支路抵 `(14,182)` 的被挖坑。玩家在坑邊 `(14,188)`、yaw `150°` 停下，看 `4.5×4 m` 的鑿痕與翻土，再回到主路向東到 D6 或向西到 D4。北路 `(4,249.5)` 留給 D7。樹林成叢，`(9,178)` 視線方向的 `2.2 m` 通道及 `(0,200)` 樹幹周圍 `5 m` 保持可走；坑緣只用局部碰撞。

## 地形、路與擺放

中心 `(0,200)` 高 `4.8 m`；南緣 `(10,152)` 高 `7.9 m`，西緣 `(−42,200)` 高 `9.5 m`，東緣 `(42,200)` 高 `9.7 m`，北緣 `(4,248)` 高 `8.2 m`。`heightPoints` 讓坡面向中心收，`relief=1.1 m`、`noise=0.22`、`cliffs=2.4 m`；入口 `(10,168)` 和跨根 `(11,194)` 兩條長條 `flats` 分別壓到 `6.8/5.1 m`。神木 pad `(0,200)` 半長 `7×7 m`，只做樹幹落地範圍；根與冠幅可跨 pad，但不能形成整圈不可通行碰撞。

路節點順序為 `(10,150.5)`→`(10,165)`→`(9,178)`→`(11,194)`→`(4,205)`；支線從 `(9,178)` 到坑 `(14,182)`，寬 `1.8 m`。從 `(4,205)` 分別接西緣 `(−49.5,214)`、東緣 `(49.5,221)`，均寬 `2.2 m`；北緣 `(4,249.5)` 路寬 `2.0 m`。四個停點 pad 是 `(0,200)` 樹基、`(7,207)` 樹下空地、`(14,182)` 坑、`(9,178)` 前景觀樹點；詳細尺寸與高度在 JSON。

JSON 明列 `17` 件：神木 `1`、CO01 坑 `1`、FR 根件 `3`、FP 步道 `4`、倒木 `2`、樹樁 `2`、BM09 蕨 `4`。其中神木來源 GLB 原始約 `10 m` 高、QA 報告約 `147222` 三角形且未通過檢查；`scale=9` 僅是目標 `90 m` 的匯入試值，不能用它聲稱手機可跑。`footprint=[93,64,90] m` 是放大後的包圍量級，只有樹幹半徑約 `5 m` 應帶碰撞。外圈填充由 `world-dressing.json` 的 ElderCypress `weight=1.0` 管，單棵特意樹在 `(−35,232)`；不得把同一棵神木再當 `landmarks` 重複生成。
