# Codex v11 第一輪審查：CO01、SS01、SR01（2026-11-14，Claude Code）

結論：**三件都不通過**，和 Josh R01／FR04、我們的 AL01 並排差距明顯。下一輪先照下面重做這三件，再接 RL01 之後的。並排比較圖改用同一個背景、同一盞燈、同一個相機距離（現在左右背景不同，不好比）。

## CO01 被挖的坑
1. 外緣是一圈平滑的圓餅，邊上看得到多邊形折角，像擺在地上的盆，不像挖進地裡。改成**沒有外壁**：外緣用很寬的斜坡（≥ 1 m）漸漸融進地面，邊緣高度 0，最後 10 cm 用頂點色淡出，讓它能接 D2 的地表。
2. 坑壁太光滑。要有一鏟一鏟挖過的痕跡（剖面凹凸、分層的土色：上層深褐腐植土、下層黃褐黏土、底部濕暗），斷根從壁裡伸出來要更多（8–12 根，粗細三級，斷口新鮮淺色）。
3. 翻出來的土堆在坑邊一側堆成一兩座不對稱的土丘，土塊和碎石混在一起；現在的石頭像貼上去的。
4. 底部要有一點積水或濕泥反光、掉進去的落葉和幾塊碎石。
5. 面數放寬：LOD0 可到 25,000，品質優先。

## SS01 半埋踏石
1. 像切好的水泥塊：側壁是直的、底下有一圈倒角稜線。改成**河石／山石**：輪廓圓鈍不規則，側面往下收進泥裡，沒有可見的底面（往下延伸 15 cm 埋入）。
2. 頂面磨平但要有微微凹陷和踩亮的區塊，不是平板；裂紋用幾何做淺溝，不只畫貼圖。
3. 苔現在是黏在角上的綠色小豆子，刪掉。苔改成從側面下緣往上長的一片片（貼著表面的薄殼或頂點色＋材質），往背光側多。
4. 參考 AL01 的 `cr_parts.rbox(hew, chips)` 做石頭的方式和 `cr_mats.stone` 材質。

## SR01 地表盤根
1. 像一根細樹枝平放在地上，太細、太直、沒入土。地表盤根要**粗（0.25–0.5 m）、貼地、半埋**：截面是扁的（寬大於高），上緣露出、下半在土裡。
2. 一端要接著樹幹方向變粗，另一端分岔再分岔（至少三級）漸細鑽進土裡，入土處有隆起的土和斷苔。
3. 表面要有扭絞的縱向稜、被踩亮的頂脊、苔和地衣在背光側。
4. 參考 AL01 `al_altar.py` 裡的 `_root()`（路徑游走、節瘤、分岔、埋入判斷），那個做法通過了 z1nnz 的「石台很好」。不過 z1nnz 說 AL01 的根也還不夠寫實，所以要更粗壯、更像真的樹根。
