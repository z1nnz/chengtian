# 樹木重做 v2：照「天空島世界樹」的做法，三人分工

> 2026-11-14，Claude Code 依 z1nnz 指示撰寫：「樹的工作量很大，畢竟我們要做蠻多顆的，所以你可以分一點給其他協作者，並且附上我們的開發指南」。
> 這一份**取代** 11/11 的 `B-64h-trees-rebuild.md` 第 3 節的葉片做法（葉片卡、葉團圖集）。樹種、高度、用在哪照舊。

## 0. 為什麼又要改

z1nnz 看過所有新樹（包括 #114 的 TR01–TR07），判定**全部還差很遠**：

1. 葉子成塊、成團：葉片卡和葉團圖集轉個角度就看得出一片片卡片。
2. 樹枝太粗、級數太少：葉子只包在外面，看不出枝在葉前、葉在枝後的層次。
3. 樹冠是球或幾顆小球拼的，不像真的樹。

標準是 z1nnz 之前做的天空島世界樹（`tree-method/標準-天空島世界樹.png`）：**一片一片的立體小葉子，沿著彎曲的枝梢流排列，三級細枝穿在葉子之間，樹冠有大小不同的空洞。** 做到這個水準，或更寫實。

## 1. 開發指南（一定要先讀完）

全部在 `docs/execution/2026-11-14/tree-method/`：

| 檔案 | 是什麼 |
|---|---|
| `天空島世界樹建模歷程與精修方法.md` | **主要指南**。第一節為什麼好看、第二節 15 步流程、第三節常見錯誤、第四節檢查表、第七節最短配方 |
| `build_life_tree.py` | 那棵樹的 Blender 產生器原始碼。重點看 `curve_branch`、`add_branch_hierarchy`、`add_solid_canopy_geometry`（葉片沿 11 股枝梢流、五頂點立體葉、依高度混色）、`build_tree`（S 形主幹、主枝） |
| `標準-天空島世界樹.png` | 驗收時並排比較的標準圖 |

**順序照指南，不可跳**：三視角黑色剪影 → S 形主幹（6–9 個控制點）→ 先 3 條決定剪影的主枝，再補到 6–10 條，不對稱 → 次枝、末梢枝三級粗細 → 12–20 個大小不同的葉冠錨點，前後兩層 → 每個錨點 7–13 股枝梢流，葉子沿枝梢參數排 → 五頂點立體葉 → 頂點色寫高度色和遮蔽 → 最後才做樹皮。

**禁止**：葉片卡、葉團圖集、在球體或橢球裡撒葉子、左右鏡像的枝、粗細一樣的枝。

## 2. 共同規格

| 項目 | 規定 |
|---|---|
| 葉片 | 五頂點立體葉（四點輪廓＋抬高的中脈），不透明、雙面、高粗糙度。依樹種改葉形和大小（松是針葉束、柳是細長葉、銀杏是扇形葉） |
| 葉色 | 頂點色：依葉子在樹冠裡的高度和內外連續混色（上外亮暖、下內深冷），A 通道寫遮蔽。顏色沉穩，照風格色票第 2、11 節，**不要螢光綠** |
| 面數 | LOD0 ≤ 60,000；LOD1 ≤ 15,000（葉子減到四分之一、單片放大）；LOD2 ≤ 4,000（遠景可以用葉團卡）；LOD3 遠景卡 ≤ 200。灌木、幼樹各減半 |
| 樹皮 | 中低頻起伏（主幹扭轉的稜、根頸膨脹、樹瘤）先用幾何做出來，再加高粗糙、低對比的樹皮材質。不要用高頻雜訊假裝細節 |
| 風 | 頂點色或第二組 UV 寫風的權重：主幹 0、主枝少、末梢和葉多 |
| 原點 | 樹幹底部中心，z = 0 在地面，根往下埋 0.3 m |
| 變體 | 每種 3 個（A、B、C），剪影要分得出來；固定亂數種子，可以重建 |
| 交件 | 照你們之前的交件規則：三視圖（先選一張再建，**參考圖可以請 Claude Code 在 ChatGPT 出**）、剪影圖、灰模、成品、線框、LOD 對照、1.75 m 人形尺、`model_info.json`、README |

## 3. 驗收（Claude Code 審，z1nnz 看）

1. **和標準圖並排**：同光、正面與左右 35°，葉子要細碎、沿枝流排列、看得到枝條層次。不如標準圖就重做。
2. 黑色剪影三張：有重心、不對稱、有大小不同的空洞。
3. 樹冠下往上看一張：看得到末梢枝穿進葉子裡。
4. 遠看 20 m、60 m 各一張：不閃、不糊。
5. 指南第四節檢查表逐項打勾，沒做到的照實寫。
