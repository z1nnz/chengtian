## 怎麼用

1. **照順序一塊一塊建**，一塊通過才接下一塊。這是建造順序，不是玩家的遊玩順序。
2. 擺法照「成組」：同一分區的東西要互相靠近，不要一件件隔開展示。
3. 每塊建完，在每個**鏡頭**的位置截圖（眼高 1.6 m、水平視角 55°），存到 `art/previews/blueprint/<區塊>/<鏡頭>.jpg`。有主視覺的並排比對。
4. 「必須看到」是驗收條件。

## 自由度

### 玩家

- 沒有規定路線：除了第 1 天從官道進村，玩家想先去哪就去哪，紅線只是常見走法。
- 每個區塊至少兩個出入口，不走回頭路也能繞回村子。
- 不用看不見的牆擋人。走不過去要看得出原因：懸崖、深水、密林；能爬的坡就讓人爬。
- 主路之外要有小徑和捷徑，走偏了要有獎勵：機緣、好風景、一個小場景。
- 故事還沒到的地方也能走到，只是事件還沒發生，不要整塊封起來。

### 建造的人

- 鎖定的只有四樣：地標、鏡頭要看到的東西、感覺、區塊之間的連接。
- 其他都可以自己決定：分區的位置和大小、件數、擺法都是建議，覺得更好就改，也可以加施工圖沒寫的東西。
- 改了就更新 world-blueprint.json，回報時說明為什麼。
- 覺得鏡頭或地標本身不對，可以提出替代方案並附截圖，由 z1nnz 決定。
