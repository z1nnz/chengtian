# 世界完成清單：做到哪裡才算完

- 日期：2026-11-11
- 依據：`tools/qingxi-terrain/world-blueprint.json`（世界施工圖，19 塊、60 個鏡位）
- 用途：回答三個問題。要做哪些模型、每個模型擺在世界的哪裡、做到什麼程度算完成。
- 數字來源：2026-11-11 用程式比對施工圖、main 上的模型檔和場景生成程式。「已擺」是看程式裡有沒有用到該模型，沒有逐一進遊戲核對。

## 一、一句話的完成定義

**第一圈 13 塊區塊，每一塊都通過下面六項檢查，就是試玩版的世界完成。**

第一圈是新手十天會走到的地方。第二圈 6 塊是自由探索區，試玩版之後再做。

### 每一塊的六項檢查

| # | 檢查 | 怎樣算過 |
|---|---|---|
| 1 | 地形 | 走得到每個重點區，不會掉出世界，不會卡住 |
| 2 | 模型 | 施工圖列的模型全部擺好，件數和位置照施工圖 |
| 3 | 植被 | 樹、草、石照施工圖的「填充」那一欄種好 |
| 4 | 氣氛 | 有霧和遠景，草不螢光，夜晚看得見東西 |
| 5 | 對圖 | 用施工圖的鏡位截圖，和主視覺並排比對，氣氛和構圖對得上 |
| 6 | 效能 | 自動測試通過；電腦可選 60、120、240 幀，手機可選 30、60、120 幀。每一檔都要穩，最低檔（電腦 60、手機 30）在最低規格的機器上也要達到 |

### 每一塊的做法（四步）

1. **主視覺**：這一塊長什麼樣，先有一張圖。
2. **擺方塊對圖**：用方塊把大小和位置擺到和主視覺一樣。
3. **換成模型**：方塊換成真的模型，缺的模型先做。
4. **光影和霧**：調到和主視覺的氣氛一樣，再截圖比對。
