# 核心組建模標準 v1：向 Josh、Eli 看齊

- 日期：2026-11-11
- 依據：z1nnz 指示「我們自己的建模都要跟他們兩個看齊，品質不如他們就要重做，要學習一下他們怎麼製作的」
- 範圍：核心組（z1nnz、Claude Code、Codex）自己做的每一件模型。協作者照各自的工作包。
- 研究對象：Josh 的 VL 民居（`art/source/village-houses-b/`）、Eli 的 WL 洗衣小物與 FI 釣具（`art/source/creekside-life-c/`）

## 一、他們怎麼做（讀程式後的整理）

### 1. 每個零件都是真的幾何，不是一塊雜訊捏出來的

- **Josh**：`cr_parts.py` 的 `rbox()` 做每一塊石頭、木板、瓦。參數有倒角、**鑿面**（`hew`，接近平行於表面的切面，讓石頭像鑿過而不是枕頭）、缺角（`chips`）、收分、歪斜、彎曲。另外有 `rope()`（多股絞繩）、`lash()`／`xlash()`（綁紮）、`pole()`（有節的竹竿）、`sheet()`（布）、`log()`、`tuft()`（草叢）。一面牆是一塊塊石頭疊出來的。
- **Eli**：`fi_items_b.py` 的 `_lathe()`（旋轉體）、`_ring()`（繞一圈再壓過起點的繩圈）、`tube()`。每件先照三視圖拆成有名字的零件。
- **我們的問題**：CO01–CO04 是一個密網格加雜訊位移，再用平面切掉幾刀。石頭像一團軟泥，看不出一塊一塊的結構。

### 2. 材質是程式化的「材料」，不是頂點色

- **Josh**：`vl_mats.py`、`cr_mats.py`、`mk_mats.py` 每種材料一個函式，例如 `plaster()`：抹灰層、屋簷下的雨痕、牆腳的濕氣、細裂、剝落露出磚層、新補的灰、釘子的鏽水。顏色**一律取自風格色票**（`modeling-style-spec-v1` 第 2 節，已換算成線性值）。
- **Eli**：每種材料平鋪貼圖（例如布的經緯線 `linen()`），烘焙時再疊陰影和磨損。
- **我們的問題**：顏色是我隨手寫的數值，不是色票；只有大塊的雜訊，沒有「這個材料會怎麼老化」的邏輯。

### 3. 烘焙不只顏色，還有好幾種輔助圖，最後用程式合成

- **Eli**（`build_wl.py`）：Cycles 烘焙 DIFFUSE 顏色、AO（96 取樣）、粗糙度、切線與物件法線、邊緣尖銳度（Pointiness）、位置；再用 numpy 合成：冷色的 AO 陰影、縫裡的髒污、磨亮的邊、下緣的濕痕。**Detail_ 零件另外烘一次 AO**，因為標準畫質會把它們藏起來，本體上不能留下它們的影子。
- **Josh**（`ti_pipeline.py`）：正規化 → 依群組合併 → UV 圖集 → 烘焙 → LOD1／LOD2 → 烘好的材質 → FBX → 10 個角度的預覽。
- **我們的問題**：只烘了顏色、法線、AO 三張，邊緣磨損和縫裡的髒都沒有。

### 4. LOD 是設計過的，不是一律減面

- **Josh**：`LOD_RULES = {0: (99, 1.0), 1: (2, .45), 2: (1, .2)}`：LOD1 拿掉細節等級 ≥ 2 的零件再減到 45 %，LOD2 拿掉等級 ≥ 1 的再減到 20 %。屋瓦另外做 LOD。
- **Eli**：FI03 的 LOD2 把網線換成畫在貼圖上的透明袋形面，遠看還認得出網袋。
- **我們的問題**：一律用減面修改器，CO05 棧道的木梁減面後直接斷掉。

### 5. 檢查和交件

- 先選三視圖，**先交灰模**（Eli 的 `CLAY` 模式）再上材質。
- 參考圖對模型的並排圖、同光同角度的前後對照、人形尺、線框。
- QA：UV 重疊（`qa_uv_overlap.py`）、背面（`backface_check.py`）、FBX 回匯誤差（`qa_fbx.py`）、網格（`qa_mesh.py`），再加 Unity 編輯器的檢查（尺寸、LOD、碰撞、用 1.75 m 膠囊走過）。
- README 照實記錄工時、審圖後改了什麼、哪裡還沒驗。

## 二、核心組從今天起的做法

1. **三視圖**：照 11/07 包的 Layout 段和 5.2、5.3 出圖，選一張存 `art/references/<ID>/`，**原尺寸檔**，不用螢幕截圖。
2. **零件**：照三視圖拆零件，每個零件用 Josh 的零件函式做（直接 import `art/source/village-houses-b/cr_parts.py`、`vl_mats.py`、`ti_pipeline.py`，不自己再寫一套）。
3. **材質**：用他們的材料函式；顏色只能從風格色票取。
4. **烘焙**：照 Eli 的烘焙清單（顏色、AO、粗糙度、法線、Pointiness、位置）合成 Albedo／Normal／ORM／MaskURP；Detail_ 零件另外烘 AO。
5. **LOD**：照 Josh 的 LOD 規則，依零件細節等級拿掉，再減面。
6. **檢查**：先灰模、再上材質；交件前跑他們的四支 QA 和 Unity 檢查。
7. **比較**：每件和同類的協作者作品並排一張（例如石件和 Josh 的 R01 乾砌石牆、小物和 Eli 的 WL），**看起來比較差就重做**，不交。
